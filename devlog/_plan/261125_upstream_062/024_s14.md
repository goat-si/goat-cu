## Security and behavior

No tool was added, removed or renamed by this step. MCP action inputs gain optional `ui_tree_revision`; window state gains optional revision and macOS link URL outputs. A scoped revision comparison uses caller identity and a fresh kernel-backed process fingerprint and refuses before dispatch. The key-stall metadata is content-free except process basename and OS handles. Installer downloads retain GOAT's no-`connect` behavior and `mcp-config` hint; the baked published upstream version is 0.61.3. No new telemetry endpoint is introduced by the step. Hover repaint observation starts only with Screen Recording and recorded direct-capture approval, and needs a complete unobscured-window observation. Edge indicator waiting does not grant additional consent.

The X11 DIP detector runs after element/query projection. If the top-level frame is absent, the prior unscaled fallback remains; on scaled X11 that may yield wrong `screenshot_frame` coordinates. This source-level risk has not been reproduced on a compositor and needs a failing-first follow-up. A read-only audit also identified pre-existing Linux AT-SPI debug logging of accessible names, possible selection fallback after uncertain dispatch, incomplete option-scan handling and first-editable/X11 target guessing; pre-existing macOS browser consent/setup observation-completeness gaps and Windows selected-bitmap teardown risk were also identified. These are handed to the subsequent fix slice rather than modifying `090_findings.md` here. Earlier S12 ext-toplevel capture remains deliberately excluded because cross-protocol window identity was not established.

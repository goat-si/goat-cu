# F10: query_dom password exposure

Base `96a4b5b2a87f8655107b4e3675d09c9f14220595`; implementation `d40d7089`. Local macOS host; no push.

The protected asset is a password input's value; the entry point is a caller-controlled selector and requested properties crossing from the page into the tool response. A caller could request properties or ancestor markup containing that value. The generated script now allows a bounded set of primitive properties, suppresses value-bearing properties for password or unknown input types, and suppresses markup for a node with a password or unclassifiable input descendant. The implicit textContent field is also suppressed on those inputs. Unsupported arbitrary attributes are omitted; non-password values and markup remain readable.

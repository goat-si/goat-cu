## Security and behavior

The portable manifest still lists 27 tools, with no added or removed names and no structural input/output schema changes after removing descriptions for comparison. Tool descriptions and shared session parameter text are shorter. At runtime the ended-session refusal now uses a structured `session_ended` tool error inside a successful daemon envelope; a live label held by another connection returns `session_owned_by_other_transport`. These are refusal/result changes, not authorization grants. A window snapshot replaces only the publishing session's earlier snapshot of that window; the caller's own handles remain protected by GOAT's process-instance checks. The shared desktop, focus and application state are not isolated by sessions.

The macOS identity guard refuses a changed observed control before an element click. The guard runs before GOAT's simulated and multi-click branches as well as the single-click route; single and middle click recheck near delivery. If a foreground activation was attempted before a late recheck failed, the result says `unverifiable` and requires a fresh read, since focus may already have changed; it never sends a second click. Background-only dispatch, target leases and post-AX-send uncertainty handling remain GOAT's. `#7806` changes presentation only: unconfirmed action text loses a leading success glyph. No new foreground escalation, global HID input, permission prompt or network sender is introduced by these changes.

Installer baked pins move from 0.49.11 to upstream's published 0.51.5; GOAT's `mcp-config --client` hint and removal of `connect` remain. Vendored telemetry source is unchanged; upstream `libs/cua/Cargo.toml` updates its metadata to 0.27.5, applied to the written-out vendored manifest and lock. GOAT builds telemetry without its HTTP sender. `vendor.sh` was attempted but failed at its unbraced zsh revision/path expansion after writing an empty targets file; the target files were restored from the exact upstream object and the written-out Cargo manifest restored and updated by hand. No release or version bump to GOAT packages was made.

The upstream option-check acceptance fixture included the already-removed `connect` command; it now checks GOAT's supported `mcp-config --client codex` and asserts `connect --client` is rejected. No GOAT test was removed. The cross-session screenshot/basis and scoped-LRU tests now assert separate session snapshots and that owner retirement still invalidates its rooted capture while preserving the other publisher. The S4-era guide test now checks `drag_delivery_uncertain`, matching the existing S4 behavior rather than the removed legacy `drag_and_drop_session` advice. The daemon late-call test asserts `session_ended` and unchanged invocation count, rather than accepting any tool error.
